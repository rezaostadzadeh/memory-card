# Memory Card Game 🧠

A fun and challenging memory card game built with React.
Test your memory by clicking on cards without clicking the same card twice!

## How to Play
- Click on any card to score a point
- You must not click the same card twice in a row
- Cards shuffle after every click
- If you click a card you've already clicked, your score resets!
- Try to beat your best score!

## Built With
- React
- JavaScript
- CSS
